# Eureka Server

## Descripción
Servidor de descubrimiento y registro para la arquitectura de microservicios.

## Función
Permite que todos los microservicios se registren automáticamente al iniciar y se descubran entre sí por nombre de aplicación, eliminando la necesidad de configurar IPs estáticas.

## Configuración
- Puerto: 8761.
- Dashboard disponible en `http://localhost:8761`.
